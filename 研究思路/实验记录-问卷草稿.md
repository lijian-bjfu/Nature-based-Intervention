### A2 筛查题（多选）

题干：

```
你是否有以下任一情况？（可多选）
```

选项：

```
曾被诊断患有精神或心理方面的疾病（如抑郁症、焦虑症等）
目前正在接受心理咨询、心理治疗或精神科治疗
患有心脏或血管方面的疾病（如心脏病、高血压）
有癫痫病史，或观看闪烁画面时出现过明显不适
目前在服用可能影响心率或情绪的药物（如抗抑郁药、抗焦虑药、降压药）
看手机或平板上的视频、玩第一人称三维游戏时，经常感到头晕或恶心
参加过本项目的预实验或测试
以上都没有
```

判定：勾选"以上都没有"之外的任何一项，不参加本实验。

### A3 GAD-2（2 题）

指导语：

```
在过去两周里，你有多少时间受到以下问题的困扰？
```

选项（0–3 计分）：

```
完全不会
好几天
一半以上的日子
几乎每天
```

题项：

```
感觉紧张、焦虑或急切
不能够停止或控制担忧
```

- 计分与判定：两题相加，0–6 分；≥ 3 分者结束实验（照付报酬，发放附心理咨询中心联系方式的说明卡）。
- 来源：GAD-7（Spitzer et al., 2006）的第 1、2 题；GAD-2 及 ≥3 分界值见 Kroenke et al. (2007)。措辞应与官方简体中文版 GAD-7 前两题一致（Claude 未能核对官方版原文，请以官方 PDF 为准）。
- 实验员另口头确认：今天身体是否不适；过去 2 小时内是否摄入咖啡因或剧烈运动（任一为"是"则改期）；视力是否正常或矫正后正常（否则不参加）。

- 反向计分：第 1、3、6、7、10、13、14、16、19 题（原题号 21、23、26、27、30、33、34、36、39）。总分 20–80；分层界值 41 分（≥ 41 为高层）。

  - 第 20 题保留 Tian 原译。Claude 此前说它多译了"感兴趣的事物"，是错的：Form Y 原题是"recent concerns and interests"，Tian 的译法与原题一致；data_sheet_1.pdf 漏了"and interests"。

```

```

```
有些
中等程度
非常明显
```

题项：

```
我感到心情平静
我是紧张的
我感到心烦意乱
我感到轻松
我感到心满意足
我感到担忧
```

- 反向计分：第 1、4、5 题。总分（6–24）× 20/6 可换算为完整版量尺（20–80）。
- 来源：Marteau & Bekker (1992) 选出的 6 题（calm, tense, upset, relaxed, content, worried；对应状态分量表第 1、3、6、15、16、17 题）；中文措辞取自 Tian et al. (2024) 补充材料第 13 节对应题目。整理前版本中"该译本即 Li & Qian (1995) 译本""Du et al. (2022) 也采用该版本"两处说法未能核实，已删去。若改用 Du et al. (2022) 的中文 STAI-S-6，需先确认其选题是否与 Marteau 相同。

### C2 焦虑 VAS（1 题）

```
请拖动滑块，标出你此刻感到焦虑的程度。
```

- 滑块 0–100，左端标"完全不焦虑"，右端标"极度焦虑"。
- 来源：Davey et al. (2007)。题目措辞为本研究自拟；只用"焦虑"一个词，不写"紧张/焦虑"，避免一题测两个概念。

### C3 I-PANAS-SF 积极与消极情绪（10 题）

指导语：

```
下面是一些描述情绪的词语。请根据你此时此刻的感受，选择每种情绪的程度。
```

选项（1–5 计分）：

```
几乎没有
有一点
中等程度
比较多
非常多
```

题项：

```
心烦的
有敌意的
警觉的
羞愧的
受鼓舞的
紧张的
坚定的
专注的
害怕的
活跃的
```

- 计分：积极情绪 = 警觉的、受鼓舞的、坚定的、专注的、活跃的；消极情绪 = 心烦的、有敌意的、羞愧的、紧张的、害怕的。
- 题序：按 Thompson (2007) 的题序排列（Upset, Hostile, Alert, Ashamed, Inspired, Nervous, Determined, Attentive, Afraid, Active；Claude 凭记忆，待核对原文），积极与消极词交错出现，不按维度分块。
- 来源：Thompson (2007)；中文版验证见 Liu et al. (2020)。已核实：Liu et al. (2020) 正文没有给出中文措辞；他们发现"警觉的（alert）"在中国样本中表现不佳，删去后 9 题模型拟合明显改善。建议施测时保留全部 10 题，分析时同时报告 10 题与去掉"警觉的"的 9 题结果。
- 中文措辞为自译，需回译核对。
- 选项说明：Thompson 和 Liu 用的是特质式选项（从不—总是）；本研究测此刻状态，选项改为程度（参照 Watson et al., 1988 的状态式说明：very slightly or not at all / a little / moderately / quite a bit / extremely）。


```
1 完全不符合
2
3
4 有些符合
5
6
7 非常符合
```

兴趣/愉悦题项：

```
我觉得刚才这段体验很吸引人，让我想多看看、多了解一些
```

- 反向计分：兴趣/愉悦第 5 题；感知选择第 3 题。

### E7 FMS 晕动（1 题）

```
在刚才的体验中，你最不舒服的时候，头晕、恶心或胃部不适的程度是多少？请用 0 到 20 之间的一个数字表示，0 表示完全没有不适，20 表示明显的晕动或恶心。
```

- 作答方式：0–20 整数（电子问卷可用滑块或下拉）。
- 来源：Keshavarz & Hecht (2011)。原研究在暴露过程中每分钟口头询问一次，本研究只在干预后回顾式询问一次。整理前版本中的"10 = 中度不适"不是原量表的锚点，已删去。
