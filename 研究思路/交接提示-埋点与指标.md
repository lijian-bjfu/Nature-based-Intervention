```

4. 数据存放位置与文件夹命名：采集位置（编辑器中、iPad 上）与项目数据文件夹 data/ 的关系；data/ 的结构（formal 与 pilot_and_test 绝对隔离）；table_flows 与 data_lab 的分工，global_settings.py 的职责，以及 data_lab "一个文件夹一个研究问题"的约定（README、log、results、save）。

   · APP 只记原始量，指标全部离线计算；

   · 分三层处理：事实（记录）、分类（离线）、解释（结合访谈与回放），不从日志直接推断动机；
```
