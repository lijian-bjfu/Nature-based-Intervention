## 一、工作方式

- **分工**：研究者做判断与验收；Claude 写每一小步的提示语，并在执行后直接读项目文件检查；Claude Code（默认 Haiku，不够用时换 Sonnet）只负责照提示语执行。
- **节奏**：一次只给一小步。执行完，研究者告诉 Claude"做完了"，Claude 检查；合格再给下一步，不合格写修正提示语。
- **为什么不用 Opus 自动派活**：第 1 步多是需要背景的判断（放哪、叫什么、旧代码留什么），且自动连续改文件不易控制。等规范定型、剩下重复性的活时，再考虑 Opus 指挥便宜模型批量做。

## 二、总体顺序（四步）

1. **工具层**：把 PhysicoBridge、PhysicoAnalysis 里能用的工具迁移过来；缺的先建空脚本占位。关键是定清每个工具的功能目标、位置、命名——这就是研究者以后的任务路径。
2. **配置与日志工具**："配方"（代码版本 + 参数 + 人工更正表）、更正表、登记表、数据与工具的版本维护：从哪里出、用哪个工具、如何编辑。
3. **数据对接**：每个工具读什么数据（来自哪）、做什么（生成新数据还是修改旧数据）、粒度（批处理还是逐点微调）。
4. **按 KANO 定开发顺序**：基本型（眼下马上要用：格式、拼接、修复，搭起基础数据集）→ 期望型（清洗、绘图、指标）→ 兴奋型（分析工具）。

第 2–4 步现在不细化，只在下面的工具登记表里预留对应列。

## 三、已定的原则

**数据**：raw（永不修改）+ 配方 → 任何一版结果都能重算；不靠存很多份数据管版本，只在里程碑处存命名快照。

**三类设置各放一处**：规范与口径 → `global_settings.py`（改动先讨论）；这次怎么跑（数据集、被试）→ 各流程的 `parameters.py`；对某个数据点的人工判断 → 人工更正表（supplementary 下）。

**批处理与逐点操作共用一套机制**：逐点工具（带标注的检查图、事件编辑）只往更正表里写，流程重跑时生效；原始数据不动。

**位置**：每位被试都要按顺序跑的步骤（含检查与修复工具）→ `analysis/table_flows/<类型>/`；开放式研究问题、跑一阵就结束的探索 → `analysis/data_lab/`。真正的处理逻辑放 `analysis/tools/`，入口脚本只读参数、调用、点 Run。

**命名**：入口脚本 = 两位数字编号 + 简短英文，按执行顺序，如 `physio/01_xdf_to_csv.py`；每个流程一个不带编号的 `parameters.py` 放共用运行设置，工具特有参数写在各自脚本开头的设置区。

**操作体验**：研究者在 VS Code 里点 Run，喜欢像操作系统那样的弹窗选择，很少用命令行。弹窗选"数据集/被试"，底层仍经 `data_access`。

**安全**（每份提示语都要带上）：不删除任何文件；要清理的移进同目录 `_to_delete/`；PhysicoBridge、PhysicoAnalysis 只读；`data/*/raw/` 只读；写盘前检查路径；不碰流程单系统、Unity 工程、track 已有实现。开工前研究者先备份 `data/`，并在 Claude Code 权限里禁止 `rm`、`rmdir`、`git clean`、`git reset --hard`。

## 六、预实验数据的已知情况（供检查时对照）

- 位置：`data/pilot_and_test/pilot/raw/<类型>/sub-P001|sub-P002/`，各有 `说明.md`。两位都是交互组，用 11-03 旧流程（无诱导后、干预后静息）。
- SensorBridge 标记是旧英文词表：`baseline_start`、`stim_start`、`stim_end`、`intervention_start`、`intervention_end`、`stop`，另有 `gap_start|…`、`gap_end|…`、`gap_seq|…` 断流记录（质量信息，不是阶段事件）。正式实验改用新流程 12 个标记，需映射到统一阶段名。
- P001 两段：重启后 LSL 时钟归零，不能按 LSL 时间戳直接拼；用 RR 流 `te` 列和 PB_UDP 流各样本的 `t_device`（手机端 Unix 秒）对齐，中间空档 13 分 20 秒（19:15:44.9–19:29:05.6）；part-2 无 ACC；基线在 part-1 中完整（约 6.1 分钟），part-1 末尾多一个冻结时刻的 `stim_start`。
- P002：`baseline_start` 与 `stim_start` 只隔约 1 秒，无静息结束标记；静息按 6 分钟截取，诱导开始 = `stim_end` − 360 s。
- 这些都写进人工更正表，不写死在代码里。
