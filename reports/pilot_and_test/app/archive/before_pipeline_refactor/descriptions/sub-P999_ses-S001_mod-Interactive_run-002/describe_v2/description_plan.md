# 一次自由探索的独立描述思路

本次对象是研究者在编辑器中的一场开发测试，不是正式被试。研究比较的是提供交互机会与被动观看，本次只有交互记录，因此描述要回答“实际发生了哪些自然接触和操作过程”，不能由此推断组间效果或心理机制。第一段不读取同目录既有描述、摘要或图片；第二段须等研究者授权后才开始。

## 先说明原理

交互机会不等于实际接收。本次优先描述成功触摸涉及的对象层、发生时间和空间位置，以及世界事件的发生与未发生原因。点击、环视和受阻用于交代接触是怎样发生的，不把操作多寡直接当作兴趣、投入或无聊。

时间和空间是过程的上下文。轨迹与朝向可以显示行为在何时、何处改变，受阻位置可以呈现操作受到的限制，但没有区域与景点标注时不擅自命名区域或推断景点访问。样本在某处重复出现不等于注视；点击命中点也不等于相机到达点。

记录质量决定描述边界。先检查会话起止、七表行数、时间顺序、采样间隔、缺失、触屏序号对应和技术异常，避免将采样中断、点击驱动的系统转向误作主动操作。

## 再说明方法

原始七表统一通过 analysis/lib/app_io.py 读取，通过 analysis/lib/paths.py 定位数据集和分析根目录。原始文件保持只读。历史值 None 仅在分析副本的指定字段中映射：tap.intent 与 tap.hit_layer 映射为 NoHit，tap/backstep 的 block_type、block_reason 映射为 NotBlocked；记录映射数量，不把 None 当缺失，也不改变其他字段。

时间长度以 session.t_device_end 减 session.t_device_start 计算，同时报告 spacetime.t_session 的观测范围。连续量按实际时间描述，不用行数乘 0.1 秒代替实际时长。轨迹折线长度按相邻 spacetime.cam_x/cam_z 的水平距离求和，明确它是采样近似；若与技术异常重叠，单列影响，不静默插补。

操作按 tap.intent、tap.hit_layer、tap.is_touched、tap.block_type/block_reason 列原始类别计数及交叉表；不把所有未触摸点击当失败。look 按既有 look_type 分开描述次数、起止、持续时间及 yaw/pitch 的净量与累计量，不合并为主动环视。backstep 与 world_event 逐条报告。is_touched 只提供最终结果，不能冒充真实出手时刻。

时间图使用实际会话时间，以原始事件点/转动段呈现。辅助按固定 60 秒分箱报告点击、触摸及受阻数量，末段单列实际时长；分箱只服务本次展示，不注册为研究指标。空间图同时区分相机轨迹、点击时相机位置与命中位置，采用等比例米制坐标，不计算网格覆盖率或被试排名。

计划输出独立脚本、机器可读摘要、详细计数与时间表、中文结果报告和三组静态图：空间分布、行为时间线、类别与环视描述。关键数字另用简单独立计算核对，并检查图中文字与布局。调试日志只在遇到具体疑点时读取指定的三个文件核对，不以调试字段替代实验表事实。

这里只做单次记录描述，不提出新的指标定义、阈值、心理分类或规范修改。所有文件保存到 describe_v2，第一段完成即停止。
