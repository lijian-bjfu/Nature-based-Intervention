# 路径浏览

## 一、问题

把一份实验记录放回空间结构里看：被试在什么时间、什么位置做了什么。单张静态图在 15 分钟的记录上会糊成一片，所以做成一个可交互的页面，用来观察行为在空间和时间上的样子，为定义逗留等行为分类、找指标阈值提供直观依据。这里只展示事实，不计算新的行为指标，也不把行为解释为兴趣、无聊或动机。

页面的信息组织按三个方面逐步建设：
1. **信息叠加**：空间结构（区域、桥、景点、空气墙）与行为数据（轨迹、停留、点击、环视、后退、世界事件、技术故障）分层叠放，各层可单独开关。（已有）
2. **信息过滤与聚焦**：用时间窗只看某一段；聚焦到某个区域、桥或景点；播放时间窗。（已有）
3. **数据之间的关系**：边做边定。

## 二、怎样用页面回答问题

| 要回答的问题 | 怎么看 |
|---|---|
| 某段时间被试在哪里、做了什么 | 拖动底部时间轴的两个滑块框出时间窗；右侧地图只显示这段时间的数据，左下「当前时间窗」给出路程、停留、点击、摸到、受阻的数量 |
| 被试是怎么走过来的 | 点「播放」；勾「固定窗长播放」则时间窗整体向后滑动，只看最近一段 |
| 在某个区域、景点里发生了什么 | 「空间结构」里点「聚焦」，或在地图上双击该范围；鼠标悬停在范围上显示时间窗内在此范围的时间 |
| 某次点击、停留的细节 | 鼠标悬停在符号上，显示会话时间等信息，可据此在旁观者系统里定位回放 |
| 点了哪里、想往哪走 | 「点击画在」切换被试位置 / 命中位置；勾「点击 → 命中连线」 |
| 环视朝哪个方向 | 勾「拖拽式环视」或「点击式环视」 |

缩放用滚轮，拖动平移，「全图」复位。颜色、透明度与图层开关保存在本机浏览器，下次打开保持。

## 三、脚本

| 文件 | 做什么 |
|---|---|
| `path_viewer.py` | **入口**。顶部 PARAMETERS 设置参数；读取实验记录与地理空间标注，整理成页面所需的数据，写出页面 |
| `viewer_template.html` | 页面模板（界面与交互）。入口脚本把数据嵌进去，生成一个独立的 HTML 文件 |

数据通过 `analysis/tools/data_access.py` 调取：实验记录用 `load()`，地理空间标注用 `load_geo()`。地理空间标注来自虚拟自然工程 `Tools ▸ NBI ▸ 地理空间标注` 的导出，位置见 `analysis/tools/paths.py` 的 `GEO_ANNOTATION`，格式规范见 `global_settings.GEO_ANNOTATION_SPEC`。

## 四、怎么运行、怎么设置参数

1. 在 VS Code 打开 `path_viewer.py`，修改顶部 `PARAMETERS`，保存，点 Run。
2. 用浏览器打开 `results/path_viewer.html`（在访达里双击即可，不需要联网）。

| 参数 | 含义 | 可选值 |
|---|---|---|
| `selection.dataset` | 哪一套数据 | `test`、`pilot`、`formal` |
| `selection.subject` | 被试编号 | 如 `P000`；一次只看一名 |
| `selection.run` | 同一被试多份记录时选哪份 | 如 `"004"`；只有一份时填 `None` |
| `stay.still_step_m` | 相邻采样水平位移不超过多少米算没动 | 默认 0.03（暂定） |
| `stay.min_seconds` | 连续没动至少多久画成一次停留 | 默认 2（暂定） |

停留的口径还在 `description/behavior` 中讨论，尚未写入规范；这里只决定页面上怎么画。

## 五、结果

`results/path_viewer.html`：单个文件，数据已嵌在里面，可以直接打开。每次运行覆盖。页面含被试行为数据，只存本机，不上传、不入库。认可要保留的页面复制到 `save/` 并按含义命名。追溯信息在 `results/_provenance/`。
