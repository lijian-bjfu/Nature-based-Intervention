# 驻留的概念定义探索

## 一、问题

《实验记录-埋点》第十节要定义"驻留"：被试在虚拟自然里"待着"在数据上是什么。初步想法是：驻留是移动的特例，一段时间窗内被试的水平活动范围不超过某个阈值。这里要用真实记录回答：

1. 活动范围这个量的分布是什么形状：是明显的两堆（可以切）、几堆有序的（有序分类），还是连成一片（只能当连续量）？
2. 如果能切，阈值大概在哪里，换一个窗长结论是否稳定？
3. 不用时间窗，只看相邻采样动没动，全程会被切成怎样的不动片段和走动片段？这些片段多长？

这里只描述行为，不把驻留解释为兴趣、专注或无聊。数据给出的切分候选，要用观察者系统回放核对，再决定写入《实验记录-埋点》第十节。

## 二、这些工具怎样帮助回答问题

| 要回答的问题 | 看哪里 |
|---|---|
| 活动半径的分布形状、能不能切、阈值在哪 | `fig1_radius_distribution`（每个窗长一幅直方图，标出 Otsu 分界与谷底）；`table_distribution.csv` |
| 换窗长结论稳不稳 | 报告"窗长稳定性"一条；`table_distribution.csv` 各行对照 |
| 活动半径随时间怎么变，在哪些时刻低、哪些时刻高 | `fig2_radius_time`（叠加点击、摸到、技术卡顿） |
| 半径和"走得多快"是不是同一件事 | `fig3_radius_vs_speed`；报告中的 Spearman 相关 |
| 不动与走动片段有多长 | `fig4_episode_durations`；报告"不动片段"一条；`table_episodes.csv` |
| 对照回放核对某一段 | `table_episodes.csv`（全程每个片段的起止秒、点击数、摸到数）；设了候选半径后还有 `table_dwell_segments.csv` |

## 三、脚本

| 脚本 | 做什么 |
|---|---|
| `dwell_range.py` | **入口**，也是唯一的脚本。顶部 PARAMETERS 设置参数；数据通过 `tools/data_access.py` 调取，计算、画图、写报告和追溯信息 |

计算口径：

- **时间窗活动半径**：对每个采样时刻，取以它为中心、长 W 秒的窗口；窗内各点到窗内平均位置的最大水平距离。只用 `cam_x`、`cam_z`。窗口超出记录开头或结尾的时刻不计算。
- **窗内平均速度**：窗内水平路程 / 窗内时长，只用来和半径对照。
- **Otsu 分界与可分性 η**：在对数半径上做二分类，η 是两类之间的方差占总方差的比例。
- **谷深比**：平滑直方图中两座最高峰之间的最低谷高度，除以较低那座峰的高度。
- **双峰系数**：旁证。相邻采样高度相关，样本数实际偏大。
- **不动／走动片段**：相邻两个采样之间位置变化不超过 `still_step_m` 算"没动"，连续的没动或动了各合并为一个片段。
- 技术卡顿只标记，不排除。

## 四、怎么运行、怎么设置参数

1. 在 VS Code 打开 `dwell_range.py`。
2. 修改顶部 `PARAMETERS`，保存。
3. 点右上角 Run。
4. 打开 `results/report.md`。

| 参数 | 含义 | 可选值 |
|---|---|---|
| `selection.dataset` | 分析哪一套数据 | `test`、`pilot`、`formal` |
| `selection.subject` | 被试编号 | 如 `P000`；一次只分析一名 |
| `selection.run` | 同一被试多份记录时选哪份 | 如 `"004"`；只有一份时填 `None` |
| `dwell.window_seconds` | 候选窗长（秒），每个都算一遍 | 数值列表，默认 2、3、5、8、12 |
| `dwell.reference_window_seconds` | 画时间曲线、列驻留段落用哪个窗长 | 必须是上一项中的一个 |
| `dwell.floor_m` | 半径下限（米），低于它按"完全没动" | 默认 0.01（位置记录精度） |
| `dwell.candidate_radius_m` | 候选"原地"半径（米） | `None` 只看分布；填数值则列出驻留段落 |
| `dwell.min_dwell_seconds` | 段落至少持续多久才列出 | 默认 2，仅在填了候选半径时起作用 |
| `dwell.still_step_m` | 相邻采样位置变化不超过多少米算没动 | 默认 0（位置完全不变） |
| `figure` | 图的分辨率、格式、字体、字号 | 一般不用改 |

## 五、结果

一次只分析一份记录。每次运行先清空 `results/` 再写入；想保留某次结果，复制到 `save/` 并按含义命名。用了哪份数据记在 `log.md` 里。

`results/` 包含：`report.md`（先写发现，再附表和图）、`table_distribution.csv`、`table_window_series.csv`（每个时刻、每个窗长的半径和速度）、`table_episodes.csv`、`fig1`–`fig4`，以及自动生成的 `_provenance/`。

## 六、结论

**逗留（已定，阈值暂定）**：把相邻的停顿串起来，从第一次停顿到最后一次停顿，活动始终在半径 R 以内、持续不少于 T，记为一次逗留；中间的小移动算在内，走进来、走出去的路不算。暂定 T = 15 s、R = 3 m，对所有被试固定。定义写入《研究思路/实验记录-埋点.md》10.2，登记在 `global_settings.METRICS["track"]["dwell"]`；路径浏览页（`description/path_viewer`）的逗留图层按此计算。

- **潜在价值**：逗留标记被试在某处投入时间的片段，可能对应观察环境，也可能对应对付操作（如反复受阻）。它是行为模式，不直接代表心理状态；两者的关系留给结合问卷、生理和访谈的分析。
- **怎么来的**：不是算出来的，而是用研究者的人工判断校准。研究者在路径图上圈出前 4 分钟的 7 段逗留，数据显示它们都在半径 ≤ 2.6 m 内持续 ≥ 18 s，未圈的停顿只有 1–5 s；R、T 据此选取。最初只看"半径内待满 T"，会把进出的路吞入（全程 85% 被判为逗留），改为以停顿为单位后，识别结果与圈出的 7 段一一对应。依据见 `save/逗留阈值校准_run004/`。
- **需要重新评估**：只有一名熟练操作者的一次记录，5–18 s 之间是空档，15 s 不比相邻值更有依据。取得预实验数据后，用敏感性检查和与人工标注对照两种方法重新评估。

**行动范围（已定）**：沿行走路径以 reach radius（0.7 m）为半径涂抹出的水平面积；占比的分母是场景可达范围（从出生点和两座桥出发、不穿过空气墙、不越出区域边界能到达的范围，整个场景只算一次、所有被试共用）。不带效价，用于被试间比较，以及交互组内的接收剂量与组内回归；区域间比较用于评估虚拟自然的设计，需考虑道路暗示、必经之路、起点等因素，并先收紧靠地形阻挡的区域边界。定义写入《实验记录-埋点》10.3，登记在 `global_settings.METRICS["track"]["footprint"]`。run-004：行动范围约 314 m²，场景可达范围约 1108 m²（重叠 27%）；半径取 0.9、1.5 m 时为 393、614 m²。

**停留与行走**：讨论中。停顿暂定为相邻采样位移 ≤ 3 cm，停顿满 2 s 是否单列为停留尚未定。

最初的"时间窗活动半径"思路（`dwell_range.py`）在这个 APP 里与走动速度几乎等价（ρ = 0.98），不作为指标使用，保留为探索记录。
